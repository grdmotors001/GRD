Import Old Data

Upload either the Excel export of your old eBill database (same layout as Book1.xlsx), or the original Access .mdb/.accdb file directly. This loads: Dealers, Products, Colours, Battery Makers, Financers, Mechanics, Production Formula (BOM), Vehicles/Chassis, Users, and Company info.

Direct Access import tries two things automatically: on Windows, the Microsoft Access ODBC driver via pyodbc (pip install pyodbc, plus the free "Microsoft Access Database Engine Redistributable" from Microsoft — match its 32/64-bit to your Python install); on Linux/Mac, the mdbtools command-line tools. If neither is available you'll get a clear error explaining both options, or you can export the Access tables to Excel and upload that instead.
